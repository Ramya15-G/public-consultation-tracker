# Public Consultation Tracker

An AI-powered platform that helps citizens discover government consultations, understand draft rules, track deadlines, and submit comments with human approval.

## Planned Features

- Browse public consultations
- AI-powered draft summaries
- Deadline tracking and updates
- Comment drafting and human approval
- Submission status and receipt tracking

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Project Status

Currently under development for the Ziro.Digital Agentic AI Hackathon 2026.
